# TournaStudio

I built TournaStudio for organizers who want to run a competition without handing their data to a service.

Create brackets, manage groups and standings, record results, and present the tournament on a second screen. The application runs in the browser and saves locally. Portable links, codes, and files move tournaments between devices.

**[Open the app](https://tournamentstudio.github.io/)**  
**[Source, tests, and documentation](https://github.com/tournamentstudio/tournamentstudio.github.io)**

The project is open source under the MIT license. There is no account requirement or backend.
