<p align="center">Your tournament. Your browser. Your data.</p>

I built TournaStudio for organizers who want to run a competition without handing their data to a service. Create a draw, record results, and put the tournament on a second screen. No account or backend is required.

The app supports knockout brackets, groups, Swiss, round robin, and multi-stage competitions. Sport presets include chess, football, esports, and Gol Ya Pooch. English and Persian interfaces, game themes, and presentation scenes help it fit the event. The [feature matrix](https://github.com/tournamentstudio/tournamentstudio.github.io/blob/main/FEATURES.md) describes the supported policies and remaining gaps.

Tournament data stays in the browser. After the app is cached, core work continues offline. Portable links, codes, and files move independent copies between devices. Keep backups: local browser storage is not permanent safekeeping, and shared snapshots do not update themselves.

## Help shape the next version

Report a reproducible bug, explain a competition rule with an example, improve a translation, or contribute code. Start with the [contributing guide](https://github.com/tournamentstudio/tournamentstudio.github.io/blob/main/CONTRIBUTING.md) or [open an issue](https://github.com/tournamentstudio/tournamentstudio.github.io/issues/new/choose). For help with tournament setup, [ask in Discussions](https://github.com/tournamentstudio/tournamentstudio.github.io/discussions). For a suspected vulnerability, use [private security reporting](https://github.com/tournamentstudio/tournamentstudio.github.io/security/advisories/new).

TournaStudio is open source under the [MIT license](https://github.com/tournamentstudio/tournamentstudio.github.io/blob/main/LICENSE). The application is a static bundle published on GitHub Pages, with tests run locally and CI disabled.
