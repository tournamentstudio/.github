# TournaStudio organization profile

This repository holds the [public organization profile](profile/README.md) shown at [github.com/tournamentstudio](https://github.com/tournamentstudio).

The application, tests, documentation, and brand assets live in [tournamentstudio.github.io](https://github.com/tournamentstudio/tournamentstudio.github.io). Open the app at [tournamentstudio.github.io](https://tournamentstudio.github.io/).

Edit `profile/README.md` to change the organization welcome page. Keep feature claims aligned with the application's [feature matrix](https://github.com/tournamentstudio/tournamentstudio.github.io/blob/main/FEATURES.md) and use its shared brand assets. This repository has no build step or CI workflow.

For application changes, use the [contributing guide](https://github.com/tournamentstudio/tournamentstudio.github.io/blob/main/CONTRIBUTING.md). For vulnerabilities, use [private security reporting](https://github.com/tournamentstudio/tournamentstudio.github.io/security/advisories/new).
